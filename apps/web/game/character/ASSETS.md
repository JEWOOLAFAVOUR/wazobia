# Asset Manifest — characters & clothing (main line)

Main now uses **zero-download procedural characters** (`SimpleAvatar.tsx`):
capsule body, sphere head, separate clothing pieces, flat-shaded to match the
in-world characters. Nothing to download, nothing to license.

The realistic-asset track (Quaternius bodies, Poly tee, official hair,
skin-transfer fitting) is parked on branch **`wip/quaternius-avatar`** —
see that branch's `public/assets/characters/quaternius/MANIFEST.md` for
sources, licenses and the required Poly attribution.
